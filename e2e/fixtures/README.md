# Test recordings

Three spoken answers for `e2e/voice.spec.ts`, one each in English, Finnish and Swedish. They were made with the product's own speech engine (Piper, the voices en_GB-cori, fi_FI-harri and sv_SE-nst), so no person's voice is in this repository. 22 050 Hz, mono, 16-bit, about twelve seconds each.

| File | What is said |
|---|---|
| `voice-en.wav` | For the last four years I have worked at a machine shop, where I look after our ERP system. I set up new items and work orders, and I wrote Python scripts that move production data into the system every night. |
| `voice-fi.wav` | Olen työskennellyt neljä vuotta konepajalla, jossa vastaan toiminnanohjausjärjestelmästä. Kirjoitin Python-skriptejä, jotka siirtävät tuotantotiedot järjestelmään joka yö. |
| `voice-sv.wav` | Jag har arbetat fyra år på en verkstad där jag ansvarar för vårt affärssystem. Jag skrev Python-skript som flyttar produktionsdata till systemet varje natt. |
